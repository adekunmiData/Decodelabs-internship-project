Decodelabs Internship Project

Overview

This repository contains the tasks and projects I completed during my Data Analysis Internship at Decodelabs. The objective of the internship was to develop practical skills in data cleaning, data analysis, data visualization, and deriving meaningful insights from real-world datasets.

	•	Exploratory Data Analysis (EDA)
	•	Data visualization
	•	Generating business insights and recommendations
